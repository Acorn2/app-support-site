# Kindred Support Site

This repository is a ready-to-publish static support site for `GitHub Pages`.
It is intended for App Store submission materials such as the support page and
privacy policy.

## Suggested Structure

```text
app-support-site/
├── index.html
├── styles.css
└── kindred/
    ├── index.html
    └── privacy.html
```

## GitHub Pages

1. Push the files to the public repository.
2. Open `Settings` -> `Pages`.
3. Under `Build and deployment`:
   - `Source`: `Deploy from a branch`
   - `Branch`: `main`
   - `Folder`: `/ (root)`
4. Save and wait a few minutes.

Your site URL will look like:

```text
https://acorn2.github.io/app-support-site/
```

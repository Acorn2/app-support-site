Scaling Rules

A homepage pattern that can grow with the app lineup

Future additions should be simple: create a folder, add support and privacy pages, then surface the new app card on this homepage.

1. Add App Folder

Create a dedicated app route

Each app should have its own folder such as `/kindred/` or `/next-app/`, so the support URL is stable and easy to submit.

2. Pair Support + Privacy

Keep the structure consistent

Every app entry should include both a support page and a privacy policy page, following the same naming pattern across the site.

3. Expose It On Home

Make the directory the source of truth

The homepage should always show which apps are live, which slots are reserved, and where each app’s support and privacy URLs live.
